# agents

Agent 相关目录。

## 内容

- `registry/`：Agent 注册（示例见 [`registry/example-agent.json`](./registry/example-agent.json)、[`registry/claude-code.json`](./registry/claude-code.json)）
- `bindings/`：Agent 与项目或运行环境的绑定信息

这里记录的是“谁能做什么”，不是任务历史。与 [`../../projects/registry/`](../../projects/registry/README.md) 的项目注册配合使用。
