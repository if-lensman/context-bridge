# Context Knowledge：写入常识到上下文仓库

## 目的

`context-bridge` 是跨项目、跨设备、跨 agent 的事实源。其他项目和 agent 在对话中产生的**可复用常识**（验证过的结论、踩坑记录、方法总结、通用文档），不应只留在原项目或聊天记录里，而应按规范写回仓库，让任何 agent 下次都能直接查到。

本 skill 只负责**知识写入和迁移的落点与格式**；它是全局 skill，在任何项目目录下都可以触发。

## 适用场景

- 「把这个结论写成常识」「记住这个经验」：当前项目/对话中的稳定认知写入仓库
- 「把项目里的 docs/文档迁移到中枢仓」：将外部项目中的文档型数据收编到本仓库
- 写完常识后需要能被展示站（`site/`）正确索引

## 不适用场景

- 注册项目的任务执行、feedback 回写、snapshot 更新 → 走 `context-bridge` 正式 skill
- 只属于单个项目、对其他项目没有复用价值的内容 → 留在原项目自己的 docs
- 项目当前进度和临时状态 → 那是 `current_snapshot.md` 的职责，不是常识

## 输入

- 要写入的内容：对话结论、经验描述，或外部项目中的文档路径
- 可选：建议的主题标签、目标位置
- 依赖：本机上 `context-bridge` 的 clone。定位方式：
  1. 当前就在该仓库内 → 直接使用
  2. 其他设备/目录 → 查看该仓库 `projects/registry/` 中中枢仓自身记录的 `local_paths`；找不到时向用户确认路径，不要猜

## 写入路由（常识落在哪）

| 内容类型 | 落点 | 索引同步 |
|---|---|---|
| 工程方法、Agent 经验、通用结论 | `docs/` 顶层或 `docs/` 下新增主题目录 | `docs/index.md` |
| 仓库级约定、流程说明 | `docs/` 顶层 | `docs/index.md` |
| 某注册项目的稳定知识（跨设备要保留） | `projects/<project-id>/docs/` | 该项目 `docs/index.md`（如存在） |

不确定落哪时，优先 `docs/` 顶层（通用经验）或对应项目的 `docs/`（项目专属），并在回复中说明选择理由。

## 格式要求（写入前必须满足）

所有新增知识 Markdown 必须带 Frontmatter：

```yaml
---
title: 面向人的稳定标题
type: explanation        # index/explanation/how-to/reference/decision/case
topics:                  # 稳定、可复用的英文 kebab-case，即知识标签
  - agent-engineering
  - linklab2             # 关联项目时加 project_id
status: stable           # draft/stable/archived
created: 2026-08-19
updated: 2026-08-19
---
```

正文要求：

- 中文撰写，技术标识保留英文原样
- 写「结论 + 为什么 + 适用边界」，不写聊天过程
- 项目相关的内容在正文中注明来源项目

## 迁移外部项目文档的流程

1. 确认迁移范围：只迁移**文档型数据**（说明、分析、手册），不迁移代码、构建产物、node_modules。
2. 脱敏检查：无 API Key、Cookie、Token、内网账号、未脱敏业务数据；发现秘密必须移除或改写后再写入。
3. 选择落点：按上面的路由表；成批同主题文档建议建子目录。
4. 去重：先在仓库中搜索是否已有同类文档；有则合并/更新，不重复建档。
5. 写入时补齐 Frontmatter，`created` 无法确认就不填，不猜旧日期。
6. 正文开头或结尾注明来源项目与迁移日期（一行即可）。
7. 同步对应索引文件。
8. 原项目的原件默认保留；是否删除原文件由用户决定，不擅自清理。

## 执行步骤

1. 定位仓库本地路径，读取最新 Git 状态。
2. 明确内容类型，按路由表确定落点。
3. 搜索目标区域确认不重复（`grep` 标题关键词即可）。
4. 写入 Markdown，满足格式要求。
5. 同步索引（`docs/index.md` / 项目级索引，按落点选择）。
6. 告知用户：可运行 `python3 site/build.py` 让展示站收录新内容（非必须，下次构建自动包含）。

## 输出

- 仓库内新增或更新的 Markdown 文件（含合规 Frontmatter）
- 对应索引文件的更新
- 简短回执：落点路径、类型、标签、来源项目

## 安全与边界

- 绝不写入 API Key、Token、Cookie、密码、内网地址、未脱敏业务数据
- 不写入只属当前对话的临时讨论；常识必须是验证过、可复用的稳定认知
- 不批量迁移旧文档刷格式；只处理用户本次指定的内容
- 不删除来源项目的原始文件，除非用户明确要求
- 仓库路径随设备变化，禁止把某台设备的绝对路径硬编码进文档内容
